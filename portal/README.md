# بوابة التحميل — portal/

صفحة ثابتة واحدة تخدم نقطة التحميل الموحّدة لتطبيق **وكيل (Wakil)**، وهي
الوريث الرسمي لمستودع **DRS-AI-Download** بعد دمج كل المستودعات في مستودع
واحد.

## الاستخدام

1. **معاينة محلية:** افتح `index.html` في أي متصفح مباشرة.
2. **النشر عبر GitHub Pages:** من إعدادات المستودع فعّل Pages على فرع `main`
   بمجلد `/portal`، وستصبح الصفحة العنوان الرسمي للتحميل.
3. **تحديث الإصدارات:** الروابط تشير إلى صفحة Releases في المستودع وتلتقط
   أحدث APK تلقائياً؛ حدّث رقم الإصدار في ترويسة الصفحة عند كل إصدار جديد.

ملفات APK لا تُرفع داخل المستودع؛ صفحة Releases هي المصدر الرسمي دائماً.
