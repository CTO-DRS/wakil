# وكيل (Wakil) 4.0.0 — التطبيق الموحّد

**تطبيق واحد، مستودع واحد، حزمة واحدة.** وكيل هو الإصدار الموحّد من عائلة
DRS AI بعد دمج ستة مستودعات كانت مبعثرة: وكيل ومساعد ذكاء اصطناعي كامل
يعملان بالكامل على الهاتف دون إنترنت — نموذج لغوي محلي، بيئة لينكس مدمجة،
أدوات هاتف حقيقية، مواقيت صلاة، نطق عربي، وOCR — ولا تغادر محادثاتك وبياناتك
الجهاز أبداً.

## ما الجديد في 4.0.0 — الدمج الكبير

جاء هذا الإصدار من دمج المشاريع الستة (`wakil` و`wakil-public` المتطابقين،
`rafeeq-ai`، `DRS-AI-Assistant`، `mosaed-os-android`، `DRS-AI-Download`) في
**تطبيق Kotlin أصلي واحد**. وكيل كان الأشمل أصلاً (llama.cpp + Vulkan،
Alpine/proot، تحكم بالشاشة، sherpa-onnx، tesseract OCR، تنزيل متوازٍ،
GitHub كامل)، فأُبقي هو الأساس ونُقلت إليه المميزات الفريدة من البقية:

- **15 أداة هاتف جديدة من رفيق** (`extra/PhoneTools.kt`): بحث جهات الاتصال
  والمكالمات، مسوّدات الرسائل وواتساب (زر الإرسال يبقى بيدك دائماً)، المنبه
  والمؤقت عبر تطبيق الساعة، قراءة التقويم وإضافة ونقل الأحداث، المصباح وعدم
  الإزعاج والسطوع، وفحص الأذونات وفتح شاشات منحها.
- **مواقيت الصلاة أم القرى من رفيق** (`extra/PrayerTimes.kt`): حساب خالص
  دون إنترنت لـ12 مدينة سعودية أو إحداثيات حرة، بأداة `prayer_times` في
  المحادثة، وبنفس مرجع الاختبار المنشور (±5 دقائق).
- **المظاهر الاختيارية للهويات المدمجة**: ثيمات رفيق AI ومساعد OS وDRS AI
  بألوانها الأصلية المستخرجة حرفيًا من كود كل مشروع قبل حذفه، تُبدَّل من
  الإعدادات ← «الثيم والألوان» (المجموع 8 ثيمات) مع سطر يوضح مصدر كل هوية.
- **145 اختبار وحدة** (كانت 122 قبل الدمج) تشمل الآن اختبارات سجل المظهر
  والألوان الموروثة والثيمات الثمانية، إضافة إلى المواقيت والأرقام السعودية.
- سبب اختيار النقل وحدود الدمج ومصير كل مستودع موثّقة بالكامل في
  [`docs/MERGE.md`](docs/MERGE.md) — وما لم يُنقل عمداً (كود GPL في DRS AI
  وأطر RN/Capacitor) محفوظ كما هو في [`archive/`](archive/) كمرجع دائم.

## أبرز القدرات (الموروثة من 3.x + المنقولة)

| المحور | التفاصيل |
|---|---|
| نماذج محلية | أي GGUF عبر بحث Hugging Face مُصفّى (حجم/عائلة)، استيراد فوري من ذاكرة الهاتف، مكتبة بمجلد مخصص، بطاقات معلومات حقيقية من الترويسة، تحذير رام قبل التحميل |
| تسريع | Vulkan اختياري للطبقات، نسخ i8mm/armv8.2، تنزيل سريع 1–8 اتصالات مع استئناف |
| لينكس مدمج | Alpine عبر proot: `apk add`، python/node/git، وبناء APK على الهاتف |
| أدوات الهاتف | الجديد في 4.0.0 — جهات اتصال، مكالمات، مسوّدات رسائل/واتساب، منبه/مؤقت، تقويم، مصباح، عدم إزعاج، سطوع، مواقيت صلاة |
| تحكم بالشاشة | قراءة عناصر، OCR عربي/إنجليزي شاشة وصور، لمس بالاسم أو الإحداثيات، كتابة وتمرير |
| صوت | نطق عربي عبر sherpa-onnx، محادثة صوتية، استيقاظ بكلمة |
| GitHub | ربط، قراءة/كتابة، قوالب مشاريع جاهزة، بناء سحابي وانتظاره وتثبيت APK |
| أتمتة | جدولة مهام دورية، ذاكرة طويلة، اختصارات شاشة رئيسية، قراءة مستندات |

## بنية المستودع

```
├── app/                    # التطبيق الواحد (Kotlin + Compose + jniLibs جاهزة)
├── scripts/                # بناء PTY والمكتبات الأصلية وأدوات الأصول
├── portal/                 # بوابة التحميل (بديل DRS-AI-Download) — صفحة ثابتة
├── docs/
│   ├── MERGE.md            # وثيقة الدمج الكاملة: من أين جاء كل شيء ولماذا
│   └── WAKIL-HISTORY-ar.md # تاريخ إصدارات وكيل من 1.x حتى 3.5.0
├── archive/                # مصادر المشاريع المتقاعدة كما وردت (مرجع فقط)
│   ├── rafeeq-ai/          # رفيق (Expo RN) — أصل أدوات الهاتف والمواقيت
│   ├── drs-ai-assistant/   # DRS AI (GPL-3.0) — مرجع منفصل بترخيصه
│   └── mosaed-os/          # مساعد OS (Capacitor) — النسخة المكتملة
├── keystore/               # مفتاح التوقيع (للمستودع الخاص)
└── BUILDING.md             # دليل البناء الأصلي المفصل
```

## البناء السريع

```bash
# JDK 17 + Android SDK 35 (التفاصيل الكاملة في BUILDING.md)
./scripts/build-pty.sh            # مرة واحدة: بناء مساعد PTY
./gradlew testDebugUnitTest       # 145 اختبار وحدة
./gradlew assembleRelease         # يتطلب WAKIL_KEYSTORE_* من البيئة (وإلا يسقط للتوقيع التجريبي)
```

على أجهزة بذاكرة محدودة أضف:
`--no-daemon --max-workers=1 -Porg.gradle.jvmargs="-Xmx1400m" -Pkotlin.compiler.execution.strategy=in-process`

## التحميل والنشر

- صفحة [بوابة التحميل](portal/index.html) هي نقطة التحميل الموحّدة (نشرها
  عبر GitHub Pages)، وروابطها تشير إلى [Releases](https://github.com/CTO-DRS/wakil/releases).
- سير العمل `.github/workflows/build.yml` يبني ويختبر ويرفع APK الموقّع عند
  وسم `v*` — سرّيات التوقيع بأسمائها الأصلية (`WAKIL_KEYSTORE_BASE64`…).
- معرّف الحزمة كما هو `com.wakil.agent` فالتحديث فوق النسخ المثبتة يعمل
  مباشرة.

## ملاحظات

- مجلد `archive/` **مستثنى من البناء** ولا يُفعّل أي سير عمل داخل مجلداته؛
  احتفظ به للنقل المستقبلي أو احذفه إن أردت مستودعاً أصغر حجماً.
- مفاتيح التوقيع (`keystore/` وملفات مosaed داخل الأرشيف) مخصصة لمستودع
  خاص — لا تجعل هذا المستودع عاماً بها إلا بعد نقلها إلى GitHub Secrets.
- تراخيص المكوّنات: كود هذا المستودع ملك DRS AI؛ llama.cpp وONNX Runtime و
  sherpa-onnx وtesseract بتراخيصها المفتوحة الأصلية، وكود DRS-AI-Assistant
  داخل الأرشيف يبقى GPL‑3.0 بترخيصه المنفصل.
