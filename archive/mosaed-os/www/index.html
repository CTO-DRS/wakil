مساعد OS

هذه حزمة الويب الافتراضية لتطبيق مساعد OS داخل مشروع DRS AI Suite. حزمة الويب الأصلية (Next.js/Capacitor) غير مضمّنة في مستودعات الأندرويد المدمجة، لذا ضع مخرجات واجهة الويب الخاصة بك في هذا المجلد (www/) ثم زامن الحزمة.

  • 1. انسخ مخرجات الواجهة إلى apps/mosaed-os/www/
  • 2. شغّل npm run sync من apps/mosaed-os/
  • 3. ابنِ الحزمة: npm run build:apk
